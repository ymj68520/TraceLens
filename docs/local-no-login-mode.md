# 临时本机免登录界面

默认现场版本仍要求手动登录。明确构建 `--local-auto-session` 前端时，
本机入口自动为 `local-auto-operator` 建立标准的短期用户 JWT，会话只存于浏览器内存。
登录表单不显示，原页面深链接及刷新后自动进入。失败时明确报错，不降级为匿名。

这是已授权单机调试配置：任何能访问本机入口的人可以作为该本机操作员使用系统。
不允许将此配置用于 LAN、反代公网、多用户环境或真实敏感检材准入；不是个人身份核验。
服务仍要求真实 JWT，服务间凭据不变，AI disabled、cgroup 出站控制继续生效。

仅 `http://localhost:8666` 或 `http://127.0.0.1:8666` 的同源 POST `/_local/session`
可请求此会话。精确 Host、Origin、Sec-Fetch-Site 检查、仅 loopback 监听、
无 CORS、无缓存、无请求日志。调用的是现有 field-auth/login，不自行签发 mock token。
私有登录请求只由入口在服务端构造，原始客户端 body 和身份头不得传递。
密码、JWT 签名密钥和服务凭据不得置于 VITE、前端代码或 Git。

后端冻结运行包不变。前端是独立的、可核验的临时覆盖层，不能继续宣称前端与
原冻结候选完全相同。部署说明保存原站点配置，停用账号/增加 token_version 可撤销会话。
恢复原站点即可重新使用原冻结前端及手动登录，不恢复旧匿名服务、不改调查数据库。
