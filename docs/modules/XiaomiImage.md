# 小米手机数据导出镜像

`xiaomi-image` 与 `harmony-backup` 并列，继续使用原任务、文件、时间线、手机页面、调查及报告流程。它适配本次 MIX 2S 材料所用的 `DMF + data + storage` EXT4 导出布局，不是小米所有物理镜像的通用解密工具；识别布局不认证采集厂商或手机型号。

## 使用

1. 运行 Linux/WSL 后端，将检材所在目录配置为 `TRACELENS_EVIDENCE_INBOX`。
2. 在原“检材预检”中选择 `.bin`，执行完整 SHA-256 预检。
3. 点击“按此来源新建小米镜像分析任务”，填写案情后提交。
4. 任务建立来源索引，继续筛选、分类、手机解析、时间线、智能分析、图谱和原报告完成门控。

原 `POST /api/tasks` 使用 `android_source: "xiaomi-image"`，带 `preflight_job_id`、`preflight_source_sha256`、`preflight_detected_kind: "xiaomi_export_image"`。服务端固定 Android 场景、要求手机解析，禁止自定义任务外输出及物理删除恢复。已存在的“MIUI 备份”仍处理 `descript.xml + .bak`，普通标准 userdata 镜像仍保留原入口。

CLI 可使用 `forensic_analyzer /path/to/export.bin --android-source xiaomi-image --no-ai --db-dir /path/to/output`。输出目录与检材分离。

## 读取与来源

- 标准库只读读取器支持该导出布局的 EXT4 extent 树和未补齐整个块的目录尾部，不挂载、不修补、不执行检材内容。
- 有效目录项继续索引；损坏目录的未验证部分明确记录覆盖警告。符号链接不跟随，重复名称不选择任意一份。
- 文件区段重叠、越界、加密、内联等不支持情况明确标记。不会将重叠的 DMF 区段按物理顺序拼接，也不会把无法读取的区段当作普通稀疏空洞。
- `xiaomi_source_meta`、`xiaomi_source_files` 保存镜像 SHA-256、文件身份、原路径、导出 inode、inode 哈希和字节区段；筛选、分类时保留这些表。文件预览、提取和业务解析使用同一份冻结索引。
- 来源路径使用可逆的百分号编码保存特殊字节，不把不能解码的名称替换成其他文件名。
- 建立索引及手机分析结束时计算完整镜像哈希。任务还核对完整预检身份；每次文件读取核对文件身份、大小、修改/变更时间及 inode 字节。
- 通用 `files.inode` 是任务的逻辑编号，来源表中的 inode 属于导出文件系统，均不声称是原手机物理定位。导出文件时间不自动当作用户活动时间。
- 单文件读取上限 8 GiB、目录深度 63、索引项 500,000；元数据及区段数有独立限制。达到限制或无法读取会显示覆盖状态，不能把“任务完成”理解为所有材料已恢复。

## 业务记录

共用 `IndexedMobileSource` 和原手机结果库，不另建任务工作流。`mobile_artifacts` 记录源路径、表/字段、主键或字节偏移、文件及 WAL 哈希、解析器版本。

- 通讯录读取基础表，并按外键关联联系人名称、联系方式和 MIME 类型；保留聚合联系人、原始联系人、数据项的区别，不把表行数直接当作人数。
- 通话、日历、短信、已知浏览器及媒体数据库按识别到的表结构读取；未知结构只作库存与覆盖说明。SQLite 主库及 WAL、SHM、journal 成组读取，无法读取某个索引/排序规则不代表整个库为空。
- MIUI 便签 `_tmp_bak` 支持已验证的 `6.2` protobuf 结构，保存正文、原始字段、记录字节范围。附件只按同应用下精确名称关联；字段 5/6 的业务时间含义尚未验证，不进入绝对时间线。
- 非 SQLite 文件、DMF、应用加密数据库不因外层镜像可读而宣称已解密。清单中的应用表示本来源包含的应用材料，不等于手机全部安装应用。

记录沿用原冻结、调查采纳与报告引用。手机数据分析摘要沿用原模型配置和预算，报告仍等待原门控完成。合成验收以本地模型、图谱、报告响应桩验证调用链，不代表实连模型的研判质量。

## 验证

`test_xiaomi_image.py` 覆盖只读索引、目录尾部、区段重叠/越界、截断与来源变化。`test_xiaomi_image_http.py` 通过真实 C++ 任务与文件读取器验证基础表关联、WAL、便签及附件、时间线、预检约束和原报告门控；支持 `--source`、`--work` 对独立真实样本验收。真实模式关闭模型，图谱仍使用本地桩。

真实检材与生成的数据不进入版本库。验收计数、能力边界和校验清单放在独立输出目录。
