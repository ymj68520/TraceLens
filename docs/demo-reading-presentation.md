# 演示阅读界面与本地翻译恢复

本次范围：整理分析页面，并恢复现有本地英文→中文阅读模型。
不恢复取证流水线模型、不启用公网 LLM、不迁移历史调查数据。

工作台大段 v7 迁移提示收拢为“历史版本 · 只读”标签；详细条件放在悬浮说明。
历史版本的备注、二次分析、报告证据等写入操作禁用，后端只读规则不变。
分析分区使用中文名称，空状态简化；不伪造分析、事件、图谱或中文译文。
中文阅读保留机器译文标识和分析原文，翻译失败仍展示原文并明确标识。
引用核对警告、证据来源和人工复核状态不能因录制而伪装成已核实。

恢复的模型是既有 `translate-en_zh-1_9`，运行器 CTranslate2/SentencePiece。
现有 archive SHA-256 与固定安装脚本一致，解压目录逐文件与 archive 验证一致。
本次不下载或升级模型。模型包 README 对原 OPUS 模型声明 CC-BY 4.0，归属说明随模型保留。

权重放在 `/srv/tracelens-field/models/translate-en_zh-1_9`，与发布代码分离。
Python 服务用 systemd `BindReadOnlyPaths` 将它映射到原读取器期待的模型位置；
发布包只有空挂载点，不复制模型文件入包，不热修改 Python/C++ 代码或编造版本。
使用部署前实时作业核查、独立本地推理验证及实际 API/浏览器确认。

译文仅写入独立阅读缓存，不修改证据快照、files/events/records 或 v7 调查库。
模型内容只在 CPU 本地推理；现有认证、网络监听、出站限制及真实样本边界继续生效。
新的二次分析/报告生成不因界面整理而自动恢复，也不绕过 v7 只读保护。
