# 安卓离线取证报告导入

本功能在 `/android?mode=report` 导入第三方工具已经生成的离线 HTML 报告。它不采集手机、不解析镜像或 MIUI `.bak`，也不生成厂商格式报告。导入结果始终标为“第三方报告派生记录”，不能代替手机原始数据。

## 支持的样本结构

当前适配的样本是龙信手机数据多路取证系统 LX-A2031-V3 3.104.10424.1659 的离线报告包：

```text
报告目录/
  index.html
  report/
    content0.html
    检材目录/
      export.db                 # 报告与检材元数据，不是聊天记录库
      report/
        content/data.js         # JSON 导航树（只解析 JSON，不执行 JS）
        content/contentN.html   # 记录正文
        resource/              # 附件
```

相对路径中的 Windows `\` 会规范化后再进行目录边界校验。播放器、EXE、页面脚本和模板不会执行，也不会被复制进导入索引。单个样本不能代表该软件所有版本；未识别的结构应明确报错或落入“其他”，不能猜测字段含义。

## 使用与来源链

在 Task 页勾选一个已完成任务并点击“关联离线报告”，或在安卓页的顶部 Task 选择器中选择任务。系统从服务器证据目录发现报告包（默认项目上级目录，可设置 `ANDROID_REPORT_SEARCH_ROOT`）；从列表选择即可导入，**不必手填文件路径**。已索引的同一报告会复用，勾选“关联当前 Task”才建立任务关联；取消勾选只解除关联，不删除报告索引。关联是人工选择，不代表已核验为同一检材。Task 的 Android 目录、ZIP、MIUI 备份仍是原始/逻辑取证文件分析的独立主流程，厂商报告只是补充来源。

后端只读扫描内容页，按导航章节建立表格行索引，在运行数据目录的 `android_report_imports/<id>/records.db` 中保存派生结果。每条记录保留检材、分类、报告页相对路径、页内锚点、表格及行号、导入时页面 SHA-256 与附件引用。已索引的附件在导入时记录 SHA-256（不超过 128 MiB）；下载前重新比对。原报告页只允许以纯文本附件下载，且下载前重新比对页面 SHA-256。来源页或附件变化会拒绝对应下载。

分类计数是“已索引表格行”数，可能包含详情表、重复展示行，**不是手机数据条数**。日期从报告显示文本提取，保持原值，不补造时区。检索是对可见文字的分页搜索；无法由导出报告恢复的原始数据库字段、删除记录真实性及手机镜像完整性不会推断。

支持目录最多 2,000 个内容页；单页 HTML 不超过 25 MiB，全部内容页合计不超过 256 MiB。单个附件超过 128 MiB、或附件累计哈希量超过 512 MiB 时仍可列出，但无法提供导入时哈希保证，界面会提示。真实案件数据不应提交到仓库；测试只用合成报告夹具。
